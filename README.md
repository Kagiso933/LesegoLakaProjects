# Lesego Laka Projects

Company website for Lesego Laka Projects: facilities maintenance, grounds and landscaping, agriculture, and supply services across Gauteng.

## Structure
- `index.html` – the full single-page site (no build step)
- `.nojekyll` – serve files as-is on GitHub Pages

## Hosting on GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
2. The custom domain is set in `CNAME` (lesegolakaprojects.com). DNS: four A records on the apex to 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153, and a CNAME for `www` to `kagiso933.github.io`.

## Before going live
- Confirm the compliance documents listed in the "For buyers" section (CSD, tax PIN, B-BBEE, CIDB).
- Add email and phone contact details.
- Replace the "Recent work" placeholder with project photos.

## Brand
Logo files are in `brand/`:
- `lockup-*.svg` / `.png` – logo with company name (colour for light backgrounds, reversed for dark, black, white)
- `mark-*.svg` / `.png` – symbol only
- `social-profile-1080.png` – Instagram / WhatsApp profile picture
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` – browser and phone icons

Colours: Deep Veld `#0E3D24`, Leaf `#1B6B3D`, Clay `#E2622A`, Mint `#7FD49C` (on dark), Mint tint `#E3F2E7`, Cream `#FAF4EA`.
Typefaces: Bricolage Grotesque (headings), Public Sans (body), IBM Plex Mono (labels).
