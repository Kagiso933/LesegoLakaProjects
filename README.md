# Lesego Laka Projects

Company website for Lesego Laka Projects: facilities maintenance, grounds and landscaping, agriculture, and supply services across Gauteng.

## Structure
- `index.html` – the full single-page site (no build step)
- `.nojekyll` – serve files as-is on GitHub Pages

## Hosting on GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
2. Add a `CNAME` file containing the company domain, and point the domain's DNS at GitHub Pages.

## Before going live
- Confirm the compliance documents listed in the "For buyers" section (CSD, tax PIN, B-BBEE, CIDB).
- Add email and phone contact details.
- Replace the "Recent work" placeholder with project photos.
